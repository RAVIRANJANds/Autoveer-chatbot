================================================================================
  AUTOVEER CHATBOT - WINDOWS ZIP (Mac se bheja gaya package)
================================================================================

STEP 1: Is ZIP ko Windows PC par kahi bhi extract karein
        (e.g. Desktop\Autoveer-Chatbot)

STEP 2: Python 3.10+ install karein (agar nahi hai)
        https://www.python.org/downloads/windows/
        Install mein tick: "Add python.exe to PATH"

STEP 3: Extracted folder mein jayein, double-click:
        install-windows.bat          (sirf pehli baar)

STEP 4: Phir har baar chalane ke liye:
        start-autoveer-chatbot.bat

STEP 5: Browser khulega: http://127.0.0.1:5500

AI chat ke liye: backend\.env file mein GEMINI_API_KEY likhein
( install ke baad .env.example se .env ban jati hai )

Detail: WINDOWS_SETUP.txt
